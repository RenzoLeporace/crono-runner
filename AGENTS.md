# Entregas de CRONO

La estructura solicitada por Renzo es permanente salvo indicación explícita posterior: la carpeta Entrega contiene únicamente Proyecto, Windows y APK.

Proyecto conserva fuentes editables, herramientas, recursos originales actuales y documentación. Windows contiene el EXE y su runtime; APK contiene el APK Android instalable. No generar ni entregar iOS. No incluir versiones antiguas, perfiles personales, bancos particulares, claves de firma o archivos temporales en paquetes publicados.

Antes de continuar, leer docs/HOJA-DE-RUTA.md: tiene el estado actual, las prioridades y las órdenes de construcción. Registrar los cambios de cada versión en CHANGELOG.md.

Para este trabajo no convocar subagentes ni realizar auditorías nuevas sin que Renzo lo solicite. Ejecutar las comprobaciones funcionales necesarias para los cambios (`python -m unittest discover -s tests`).

Conservar los IDs de mapas, preguntas y guardados existentes. Las adiciones no deben desplazar contenido anterior ni sobrescribir ediciones docentes.
